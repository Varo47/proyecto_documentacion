# Glosario de Desarrollo Web

Definiciones rápidas de términos esenciales en el desarrollo de aplicaciones web.

## Términos clave
* **DOM (*Document Object Model*):** Representación estructurada en árbol de un documento HTML en el navegador.
* **HTTP/HTTPS:** Protocolo de transferencia de hipertexto (seguro mediante cifrado TLS).
* **API (*Application Programming Interface*):** Conjunto de definiciones y protocolos para integrar software.
* **Responsive Design:** Diseño web adaptable a cualquier tamaño de pantalla.

* **Dominio:** Nombre único que identifica a un sitio web en Internet.
