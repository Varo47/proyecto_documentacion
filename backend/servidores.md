# Servidores Web

Un servidor web procesa las peticiones HTTP/HTTPS de los clientes y devuelve respuestas con recursos o datos.

## Servidores populares
* **Nginx:** Alto rendimiento y proxy inverso.
* **Apache HTTP Server:** Modular y ampliamente utilizado.
* **Node.js:** Entorno de ejecución JavaScript en el servidor.

Más detalles en [Nginx Docs](https://nginx.org).
