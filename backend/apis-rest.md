# APIs REST

Una API REST permite la comunicación entre frontend y backend intercambiando datos habitualmente en formato JSON.

## Métodos HTTP principales
* **GET:** Obtener recursos.
* **POST:** Crear nuevos recursos.
* **PUT / PATCH:** Actualizar recursos existentes.
* **DELETE:** Eliminar recursos.

Estándar de especificación en [OpenAPI](https://openapis.org).
