# HTML Básico

HTML (*HyperText Markup Language*) define la estructura y el contenido semántico de las páginas web.

## Etiquetas fundamentales
* `<header>`, `<main>` y `<footer>` para estructurar secciones.
* `<h1>` a `<h6>` para jerarquía de encabezados.
* `<a>`, `<img>` y `<ul>` para enlaces, imágenes y listas.

Referencia completa en [HTML Living Standard](https://whatwg.org).

* `<form>`, `<input>` y `<button>` para crear formularios.
