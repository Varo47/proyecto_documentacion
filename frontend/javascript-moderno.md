# JavaScript Moderno

JavaScript aporta dinamismo, interactividad y lógica en el navegador mediante el estándar ECMAScript.

## Características clave (ES6+)
* Declaración de variables con `let` y `const`.
* Funciones flecha (*arrow functions*) y desestructuración.
* Programación asíncrona mediante `Promesas` y `async/await`.

Aprende más en [JavaScript.info](https://javascript.info).

* **Manipulación del DOM:** Selección y modificación dinámica de elementos HTML.
