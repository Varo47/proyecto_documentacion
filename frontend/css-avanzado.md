# CSS Avanzado

CSS (*Cascading Style Sheets*) controla la presentación visual, colores, tipografías y distribución del diseño.

## Técnicas modernas
* **Flexbox:** Alineación unidimensional de elementos.
* **CSS Grid:** Maquetación bidimensional compleja.
* **Media Queries:** Adaptación *responsive* a móviles y tablets.

Guía práctica en [CSS-Tricks](https://css-tricks.com).

* **Animaciones y transiciones:** Efectos visuales fluidos sin JavaScript.
