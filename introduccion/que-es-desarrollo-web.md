# ¿Qué es el Desarrollo Web?

El desarrollo web es el proceso de creación y mantenimiento de sitios y aplicaciones accesibles a través de Internet o de una intranet.

## Áreas principales
* **Frontend:** Parte visual e interactiva que ejecuta el navegador del usuario.
* **Backend:** Lógica de negocio, servidores y bases de datos.
* **Full Stack:** Combinación de ambas disciplinas.

Más información en [MDN Web Docs](https://mozilla.org).

* **Accesibilidad Web:** Diseño inclusivo para todo tipo de usuarios.
