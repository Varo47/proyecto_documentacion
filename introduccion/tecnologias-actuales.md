# Tecnologías Actuales

El ecosistema web actual se basa en estándares abiertos y herramientas modernas.

## Estándares base
* **HTML5:** Estructura semántica del contenido.
* **CSS3:** Diseño visual y adaptativo (*responsive*).
* **JavaScript (ES6+):** Programación e interactividad.

Documentación de estándares en [WHATWG](https://whatwg.org).

* **Git y GitHub:** Control de versiones y trabajo colaborativo.
